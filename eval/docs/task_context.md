Тестовое задание:

Представьте свое видение ai-driven development для проекта по бекенду

Вводные данные: 3 бекенд-программиста, работают через claude/codex

Контекст: представлена общая схема проекта без мелких деталей бизнес-процессов, у проекта нет полной документации, часть ограничений видны по коду, часть ограничений лежит на БД(примерно 50 таблиц)

Задача:
1. Поддержание человекопонятной полной документации и её поддержание при изменениях\расширении функционала
2. Получение контекста нейронками при новой задаче у разработчиков: изменение одного блока может влиять на другие блоки - полный проход каждый раз сжигает кучу токенов и может пропустить неочевидные связи

Очевидное решение с кучей md не подходит: проект большой, связей много - grep будет что-то пропускать, принудительный cat проедает токены просто так
Важное уточнение: написание кода системы по md нас не интересует
Формат ответа: текстовый/md-файл
Основа не декомпозиция проекта, а методы внедрения ии-контекста по сложному проекту
