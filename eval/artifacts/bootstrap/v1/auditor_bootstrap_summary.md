
## Итог по модели знаний после bootstrap

**Покрытие эталона:** 66 из 68 правил — `full`, 2 — `partial`, ни одного `none`. Скрытые связи H1–H7 в модели есть почти везде: триггеры БД, цепочки событий между сервисами, guard'ы в BPM, расхождение литерала 30 дней с `LOAN_PERIOD_DAYS`, TEMPLATE_GROUP debt→paid, слушатель ORM `client.updated` без email.

- **GT-VEN-07 — partial.** Механика сброса записей при смене площадки описана, но не сказано, что на v0 эта ветка недостижима. Хуже того, R-SCHED-VENUE-CHANGE-01 утверждает обратное.
- **GT-ARC-03 — partial.** То, что заявки после выдачи ссылки или после оплаты сами в архив не уходят, следует только из перечня этапов в задаче `archive_stale`. Явно в модели этого нет.

**Корректность модели:** из 162 правил 158 — `yes`, 4 — `partial`, `no` нет.

- **R-SCHED-VENUE-CHANGE-01.** В расхождении сказано, что смена площадки у debt/social на `books_out` проходит. Это ошибка: `forbid_venue_change` запрещает её на `books_out` для любого вида (`migrations/versions/0001_initial.py:128`). Правило противоречит R-APP-VENUE-CHANGE-02, и это противоречие стоит снять.
- **R-CHAT-EVENTS-03 (verified).** Утверждается, что рядом со сменой площадки нет записи `stage_changed`. Для платной заявки в `awaiting_payment` она появляется по цепочке `invoice.cancelled` → `awaiting_payment->awaiting_invoice`. Это ошибка в правиле со статусом verified, поэтому ревью стоит перепроверить.
- **R-SCHEMA-LINK-01.** Неточно описаны публичные операции по ссылке: переноса по ссылке нет, а отмена к токену не привязана (оценка с `confidence: low`).
- **R-BILL-FINE-02.** Правило верное, но вывод «заявку можно закрыть без штрафа» правдоподобен, а не доказан (`confidence: low`).

**Что в модели ценно сверх эталона:** найденные расхождения подтверждаются кодом:
- после перепроверки по `client.updated` заявку может сразу забрать автоархив (`review_started_at` не сбрасывается);
- `OPEN_STAGES` включает `awaiting_issue`, поэтому более поздний «победитель» закрывает уже оплаченную заявку;
- для социальных заявок дедупликация не запускается вообще;
- при частичной оплате смена площадки оставляет счёт на реквизитах и ценах старой площадки;
- роли в API чата, при отмене записи и при платежах не проверяются.

Все тесты, указанные в `tested_by`, в `tests/` есть.
