Разрешить выдачу по платной заявке после оплаты не менее 50% суммы счёта за книги. Заявка должна переходить к записи на выдачу в момент, когда привязанные платежи покрывают половину счёта, и всё, что сейчас происходит в момент полной оплаты, должно происходить в этот момент. Счета на штрафы по-прежнему гасятся только полной оплатой.

Сделай изменение полностью: код, миграции (если нужны) и тесты. Существующие тесты должны проходить (`uv run pytest`), линтер — `uv run ruff check .`. БД для тестов поднимается через `docker compose up -d`.
