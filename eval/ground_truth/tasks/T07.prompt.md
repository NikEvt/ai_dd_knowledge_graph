Когда администратор меняет максимум мест в окне для площадки, будущие окна этой площадки, у которых число мест было равно старому максимуму, должны получить новый максимум. Окна, где проверяющий оператор уменьшил число мест, и прошедшие окна не меняются.

Сделай изменение полностью: код, миграции (если нужны) и тесты. Существующие тесты должны проходить (`uv run pytest`), линтер — `uv run ruff check .`. БД для тестов поднимается через `docker compose up -d`.
