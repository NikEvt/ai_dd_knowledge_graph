Добавить в данные клиента СНИЛС (поле `snils`). Без СНИЛС заявка не проходит проверку. Изменение СНИЛС — это изменение данных клиента со всеми последствиями, как при смене паспорта. Обновляет СНИЛС проверяющий, как и остальные данные клиента.

Сделай изменение полностью: код, миграции (если нужны) и тесты. Существующие тесты должны проходить (`uv run pytest`), линтер — `uv run ruff check .`. БД для тестов поднимается через `docker compose up -d`.
