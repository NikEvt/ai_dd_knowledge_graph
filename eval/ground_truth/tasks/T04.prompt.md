Правило «у клиента по одной сфере остаётся одна заявка» должно действовать и между социальной и платной (или в долг) заявками — сейчас они не пересекаются. Социальная заявка считается дошедшей до записи в момент прохождения проверки.

Сделай изменение полностью: код, миграции (если нужны) и тесты. Существующие тесты должны проходить (`uv run pytest`), линтер — `uv run ruff check .`. БД для тестов поднимается через `docker compose up -d`.
