# Требования: чат заявки

## REQ-CHAT-01 Один чат на заявку, общий для всех попыток
владелец: продукт · статус: предложено · схема: §15

Чат есть только внутри заявки. Один чат на заявку, общий для всех попыток.

## REQ-CHAT-02 Пишут в чат только закреплённые сотрудники
владелец: продукт · статус: предложено · схема: §15

Писать в чат могут только сотрудники, закреплённые за заявкой: оператор, проверяющий, бухгалтер, проверяющий
оператор.

## REQ-CHAT-03 Кто видит чат
владелец: продукт · статус: предложено · схема: §2, §15

Кроме закреплённых сотрудников чат видит только администратор, и только читает его. Главный бухгалтер и
руководитель проверяющих чат не видят. Клиент и представитель чат не видят.

## REQ-CHAT-04 В чат попадают все события заявки
владелец: продукт · статус: предложено · схема: §15

В чат автоматически попадают все события заявки: смена этапа, назначения, счета, платежи, запись, перенос и
отмена визита, неявка, уход в архив и возврат из него.

## REQ-CHAT-05 Сообщения нельзя менять, можно прикреплять файлы
владелец: продукт · статус: предложено · схема: §15

Сообщения чата нельзя редактировать и удалять. К сообщениям можно прикреплять файлы.

## REQ-CHAT-06 После закрытия заявки чат только для чтения
владелец: продукт · статус: предложено · схема: §15

После закрытия заявки писать в чат нельзя, его можно только читать.
