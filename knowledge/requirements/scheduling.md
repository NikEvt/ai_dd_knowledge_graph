# Требования: расписание и запись на визит

## REQ-SLOT-01 Окна ведёт проверяющий оператор своей площадки по сферам
владелец: продукт · статус: предложено · схема: §2, §12

Окна времени выставляет и убирает проверяющий оператор, только для своей площадки и по каждой сфере. Одно и то
же окно подходит и для выдачи, и для приёма книг.

## REQ-SLOT-02 Окно на прошедшее время создать нельзя
владелец: продукт · статус: предложено · схема: §12

Нельзя создать окно на прошедшее время.

## REQ-SLOT-03 Мест в окне не больше максимума площадки
владелец: продукт · статус: предложено · схема: §2, §12

На одно окно могут записаться несколько клиентов. Максимум мест на окно задаёт администратор для площадки.
Проверяющий оператор может уменьшить число мест в конкретном окне, но не может поставить больше максимума.

## REQ-SLOT-04 Окно с записью убирают только с отменой записи
владелец: продукт · статус: предложено · схема: §12

Окно, на которое уже записан клиент, можно убрать только с отменой записи. Клиент и представитель получают
письмо об отмене, событие появляется в чате заявки.

## REQ-SLOT-05 По ссылке видны только подходящие свободные окна
владелец: продукт · статус: предложено · схема: §12

По ссылке видны только будущие окна площадки и сферы заявки, в которых остались свободные места.

## REQ-BOOK-01 Ссылка на запись формируется, когда заявка готова к визиту
владелец: продукт · статус: предложено · схема: §13

Публичная ссылка на запись формируется и уходит, когда заявка готова к визиту: за книгами — на этапе «Ожидает
выдачи», для сдачи — когда книги у клиента.

## REQ-BOOK-02 Кто записывает на визит
владелец: продукт · статус: предложено · схема: §2, §13

Записать на визит может клиент или представитель по ссылке либо оператор в системе.

## REQ-BOOK-03 Запись только в своё свободное будущее окно
владелец: продукт · статус: предложено · схема: §2

Клиент выбирает свободное окно на площадке и в сфере своей заявки. Записаться на другую площадку, в другую сферу,
на занятое или прошедшее время нельзя.

## REQ-BOOK-04 Перенос и отмена визита — не позднее чем за два дня
владелец: продукт · статус: предложено · схема: §2, §13

Перенос — это отмена записи и новая запись. По ссылке перенести или отменить визит можно не позднее чем за два
дня до даты. Менее чем за два дня перенести визит может только оператор.

## REQ-BOOK-05 Неявка отменяет запись, но не попытку
владелец: продукт · статус: предложено · схема: §5, §13

Если клиент не пришёл, проверяющий оператор отмечает неявку и отменяет запись. Попытка не закрывается: клиент
снова может записаться. Отмена визита или неявка сами по себе не отправляют заявку в архив.

## REQ-BOOK-06 По ссылке нельзя изменить данные заявки
владелец: продукт · статус: предложено · схема: §13

Через ссылку можно только выбрать окно, записаться, перенести или отменить визит.

## REQ-BOOK-07 По заявке в архиве и закрытой ссылка не работает
владелец: продукт · статус: предложено · схема: §5, §13

Ссылка не работает, пока заявка в архиве, и после закрытия заявки.
