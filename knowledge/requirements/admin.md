# Требования: админка

## REQ-ADMIN-01 Условия представителя задаёт администратор
владелец: продукт · статус: предложено · схема: §2, §10

Администратор задаёт условия надбавки для каждого представителя и разрешает представителю работать в долг.

## REQ-ADMIN-02 Реквизиты организации площадки вносит администратор
владелец: продукт · статус: предложено · схема: §2

Администратор вносит реквизиты организации на площадке для выставления счетов.

## REQ-ADMIN-03 Размеры штрафов задаёт администратор
владелец: продукт · статус: предложено · схема: §2, §14

Администратор задаёт в админке размеры штрафов (просрочка, утеря, порча) в зависимости от представителя и
площадки.
