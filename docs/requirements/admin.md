# Требования: admin

Источник: [`knowledge/requirements/admin.md`](../../knowledge/requirements/admin.md)

## REQ-ADMIN-01

**Условия представителя задаёт администратор**

предложено · владелец: продукт · схема: §2, §10

Администратор задаёт условия надбавки для каждого представителя и разрешает представителю работать в долг.

- Реализуют: [R-APP-ADMIN-01](../rules/applications.md) (⚠ расхождение с требованием или открытый вопрос)

## REQ-ADMIN-02

**Реквизиты организации площадки вносит администратор**

предложено · владелец: продукт · схема: §2

Администратор вносит реквизиты организации на площадке для выставления счетов.

- Реализуют: [R-APP-ADMIN-02](../rules/applications.md) (⚠ расхождение с требованием или открытый вопрос)

## REQ-ADMIN-03

**Размеры штрафов задаёт администратор**

предложено · владелец: продукт · схема: §2, §14

Администратор задаёт в админке размеры штрафов (просрочка, утеря, порча) в зависимости от представителя и площадки.

- Реализуют: ⚠ правил нет — в коде не реализовано
