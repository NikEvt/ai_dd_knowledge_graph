# Требования: chat

Источник: [`knowledge/requirements/chat.md`](../../knowledge/requirements/chat.md)

## REQ-CHAT-01

**Один чат на заявку, общий для всех попыток**

предложено · владелец: продукт · схема: §15

Чат есть только внутри заявки. Один чат на заявку, общий для всех попыток.

- Реализуют: [R-CHAT-READ-03](../rules/chat.md) (подкреплено кодом и тестами)

## REQ-CHAT-02

**Пишут в чат только закреплённые сотрудники**

предложено · владелец: продукт · схема: §15

Писать в чат могут только сотрудники, закреплённые за заявкой: оператор, проверяющий, бухгалтер, проверяющий оператор.

- Реализуют: [R-BILL-ASSIGN-04](../rules/billing.md) (⚠ без тестов), [R-CHAT-PARTICIPANTS-01](../rules/chat.md) (подкреплено кодом и тестами), [R-CHAT-PARTICIPANTS-02](../rules/chat.md) (⚠ без тестов), [R-CHAT-POST-02](../rules/chat.md) (подкреплено кодом и тестами)

## REQ-CHAT-03

**Кто видит чат**

предложено · владелец: продукт · схема: §2, §15

Кроме закреплённых сотрудников чат видит только администратор, и только читает его. Главный бухгалтер и руководитель проверяющих чат не видят. Клиент и представитель чат не видят.

- Реализуют: [R-CHAT-READ-01](../rules/chat.md) (подкреплено кодом и тестами), [R-CHAT-READ-02](../rules/chat.md) (подкреплено кодом и тестами), [R-CHAT-READ-04](../rules/chat.md) (подкреплено кодом и тестами)
- ⚠ Расходятся: R-CHAT-AUTH-01

## REQ-CHAT-04

**В чат попадают все события заявки**

предложено · владелец: продукт · схема: §15

В чат автоматически попадают все события заявки: смена этапа, назначения, счета, платежи, запись, перенос и отмена визита, неявка, уход в архив и возврат из него.

- Реализуют: [R-APP-CHAT-01](../rules/applications.md) (подкреплено кодом и тестами), [R-CHAT-EVENTS-01](../rules/chat.md) (проверено человеком), [R-CHAT-EVENTS-02](../rules/chat.md) (⚠ расхождение с требованием или открытый вопрос), [R-CHAT-EVENTS-03](../rules/chat.md) (проверено человеком), [R-CHAT-EVENTS-04](../rules/chat.md) (⚠ без тестов), [R-CHAT-EVENTS-08](../rules/chat.md) (⚠ расхождение с требованием или открытый вопрос), [R-NOTIF-CHAT-01](../rules/notifications.md) (⚠ без тестов), [R-SCHED-BOOK-EVENT-01](../rules/scheduling.md) (проверено человеком), [R-SCHED-CANCEL-01](../rules/scheduling.md) (подкреплено кодом и тестами)
- ⚠ Расходятся: R-CHAT-EVENTS-06, R-CHAT-EVENTS-07, R-SCHED-FINE-01

## REQ-CHAT-05

**Сообщения нельзя менять, можно прикреплять файлы**

предложено · владелец: продукт · схема: §15

Сообщения чата нельзя редактировать и удалять. К сообщениям можно прикреплять файлы.

- Реализуют: [R-CHAT-DB-02](../rules/chat.md) (⚠ без тестов)
- ⚠ Расходятся: R-CHAT-POST-03

## REQ-CHAT-06

**После закрытия заявки чат только для чтения**

предложено · владелец: продукт · схема: §15

После закрытия заявки писать в чат нельзя, его можно только читать.

- Реализуют: [R-CHAT-POST-01](../rules/chat.md) (проверено человеком)
